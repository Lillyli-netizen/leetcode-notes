## Python 刷题通用写法

### 力扣的提交格式

只写 `Solution` 类里的一个方法。不用写输入输出，不用 `print`，判题机会自己调用 `Solution().runningSum(nums)`。

```python
class Solution:
    def runningSum(self, nums):
        ...
```

### 循环变量命名

| 写法                         | 变量含义       | 取到的值   |
| ---------------------------- | -------------- | ---------- |
| `for x in nums:`             | `x` 是元素的值 | 1, 2, 3, 4 |
| `for i in range(len(nums)):` | `i` 是下标     | 0, 1, 2, 3 |

遍历值用 `x`、`n`、`num`；遍历索引用 `i`，取值要写 `nums[i]`。

循环语法见 [Python基础03 条件判断、模式匹配与循环](https://blog.csdn.net/qq_63283852/article/details/166015640)。

### 容器初始化

装答案的列表初始化成 `[]`。写成 `0` 会得到整数，整数没有 `append`。

实例：[1480 的卡点第 1 条](0148_running-sum.md)。

列表、字典的方法见 [Python基础04 数据容器](https://blog.csdn.net/qq_63283852/article/details/166257142)。

## 常见报错

异常与报错处理见 [Python基础07 面向对象与异常处理](https://blog.csdn.net/qq_63283852/article/details/166643107)。

| 报错             | 真实含义               | 典型场景                                |
| ---------------- | ---------------------- | --------------------------------------- |
| `SyntaxError`    | 语法错，程序还没跑起来 | 全角 `：`、中文括号、漏冒号             |
| `NameError`      | 用了一个没定义的名字   | 循环变量写 `i`，循环体里用 `x`          |
| `AttributeError` | 对象没有这个属性或方法 | `result = 0` 之后调用 `result.append()` |
| `TypeError`      | 类型不匹配             | `"a" + 1`、`None + 1`                   |
| `IndexError`     | 下标越界               | 空列表取 `nums[0]`                      |

报错信息先读最后一行，那里才是错误类型。

## 判断要不要额外变量

> 看这一轮要用到上一轮的什么东西，那个东西就必须存下来。

| 题目         | 是否依赖上一轮             | 需要的变量   |
| ------------ | -------------------------- | ------------ |
| 每个数乘 2   | 不依赖，结果只跟当前数有关 | 不需要       |
| 找数组最大值 | 依赖「目前见过的最大值」   | `max_so_far` |
| 累加和       | 依赖「前面所有项的和」     | `total`      |
| 统计出现次数 | 依赖「已经数了多少个」     | `count`      |

## 边界怎么想

| 类型     | 例子                         | 检查什么                                |
| -------- | ---------------------------- | --------------------------------------- |
| 空       | `[]`、`""`                   | 循环一次都不跑时，返回值对不对          |
| 最小     | `[5]`、`[1]`                 | 只有一轮时初始化是否正确                |
| 极端值   | 全负数、全 0、很大的数       | 有没有「默认值是 0 就跳过」这类隐藏假设 |
| 特殊结构 | 重复元素、已排序、只有一个解 | 分支是否覆盖完整                        |

检查方法：对着每一行代码问「如果这里没有东西，会怎样？」

## 复杂度怎么看

**时间**：数循环。一层循环遍历 `n` 个元素是 O(n)；两层嵌套各 `n` 是 O(n²)；每次把规模减半是 O(log n)。

**空间**：数额外开的变量和容器。只用了几个变量是 O(1)；开了一个和输入等长的列表是 O(n)。

| 场景             | 时间     | 空间 | 原因                         |
| ---------------- | -------- | ---- | ---------------------------- |
| 1480 累加和      | O(n)     | O(n) | 一次遍历；结果列表和输入等长 |
| 判断是否存在某数 | O(n)     | O(1) | 一次遍历，只存一个标记       |
| 二分查找         | O(log n) | O(1) | 每轮区间减半，不用额外容器   |

## Tips

### 1. 先写中文，再写代码

中文都写不出来，说明还没想清楚，这时候看题解等于抄。

```python
# 1. 建空列表 result
# 2. 建累加变量 total = 0
# 3. 遍历 nums 的每个 x：total += x，把 total 追加到 result
# 4. 返回 result
```

### 2. 先写框架，再填内容

先把 `def` 和最后一行 `return` 写上，再补中间逻辑。漏返回、漏初始化，都能被这一步挡住。

```python
class Solution:
    def runningSum(self, nums):
        result = []          # 出口用的容器先准备好
        for x in nums:
            ...              # 中间逻辑后补
        return result        # 先把这行写上
```

### 3. 报错先读最后一行

最后一行才是错误类型，前面的行是调用栈。

```
AttributeError: 'int' object has no attribute 'append'
```

### 4. 不知道对象有什么方法，用 `dir()` 查

```python
print(dir([]))   # 列表的方法，里面有 append
print(dir(0))    # 整数的方法，里面没有 append
```

### 5. 结果容器初始化成空列表

```python
result = []      # 正确，list 才有 append
result = 0       # 错误，int 没有 append
```
